# 名前フラクタル

名前やふりがなから、その人だけのフラクタル模様を作るブラウザーアプリです。蒼阿祭の専門展示用に制作しました。WebGL（GPU）で描画するため、インストール不要でブラウザーだけで動作します。

## 主な機能

- **名前からフラクタルを生成**：名前・ふりがなをハッシュ化した数値から、形・色・回転・細かさを決定します。同じ名前なら同じ作品になります。
- **形を選べる（6種類）**：ジュリア / べき乗 / 燃える船 / 船ジュリア / トリコーン / ニュートン（「おまかせ」は名前から自動選択）
- **色を選べる（5種類）**：おまかせ / 寒色 / 暖色 / ビビッド / パステル
- **放置時のデモ表示**：45秒間操作がないと、サンプルの名前で形と色が自動的に切り替わります。
- **画質の自動調整**：フレームレートに応じて、描画解像度とアンチエイリアスを自動で上げ下げします。
- **画像の保存**：名前・ふりがな・形・色のタグを付けた PNG（1920×1080）を保存します。
- **QRコードでスマホに受け渡し**：QRコードを読み取ったスマホ上で同じ作品を再描画し、縦長の PNG として保存できます。
- **解説ページ**：`explanation.html` で、フラクタルができるしくみを紹介しています。

## ファイル構成

```
index.html            入口（name-fractal.html へ自動で移動）
name-fractal.html     作品ページ（アプリ本体）
explanation.html      解説ページ
css/
  style.css           アプリの見た目
  explanation.css     解説ページの見た目
js/
  webgl-renderer.js   WebGL の準備とシェーダー（フラクタルの計算・色づけ）
  name-parameters.js  名前から各種パラメーターを作る処理
  presets-ui.js       形・色のプリセットと選択状態
  animation.js        描画ループ、回転、画質の自動調整
  export-artwork.js   保存用画像に名前プレートを付ける処理
  controls.js         入力、画像保存、放置デモ
  qrcode.js           QRコード生成ライブラリ（同梱）
  share.js            QRコードの発行と、スマホ側の表示・保存
```

## ローカルで開く

`index.html` をブラウザーで開くと、作品ページに移動します。

QRコードに入るURLは、`js/share.js` の `SHARE_BASE_URL`（公開URL）を基に作られます。そのため、ローカルで開いたときも QR の発行はできますが、スマホで読み取ると**公開中のサイト**が開きます。変更後のコードを QR 経由で試すには、先に公開サイトを更新する必要があります。

## Netlify で公開する

### 手動でアップロードする方法（かんたん）

1. [Netlify](https://www.netlify.com/) にログインし、チームの **Projects**（Sites）画面を開きます。
2. **Add new project**（または **Add new site**）から、**Deploy manually**（手動デプロイ）を選びます。
3. このフォルダーをそのままドラッグ＆ドロップします。`index.html` が入っているフォルダーを指定してください。
4. 公開URLが表示されたら、URLを開いて表示を確認します。

### 公開URLを変えたとき

サイト名を変更した場合や、別のサービスへ移した場合は、`js/share.js` の先頭にある次の行を新しい公開URLに書き換えて、再度アップロードします。

```js
const SHARE_BASE_URL = "https://（公開URL）/name-fractal.html";
```

書き換えを忘れると、QRコードが古いURLを指したままになります。

### 更新するときの注意

- Netlify の無料プランには、デプロイ・転送量・リクエスト数などで消費する**クレジット制の上限**があります。上限に達すると、サイトが一時停止されることがあります。
- デプロイのたびにクレジットを消費するため、**動作確認は先にローカルで済ませ、アップロードは必要なときだけ**にしましょう。
- 残りのクレジットは、Netlify の **Usage and billing**（使用状況と請求）で確認できます。
- 料金やクレジットの条件は変更されることがあります。最新の内容は Netlify の公式ページで確認してください。

## 上限が来てNetlifyが使えなくなった時の代替手段

・Cloudflare Pages
静的サイトを無料で公開（転送量の制限がゆるいのが特徴）
Netlifyに一番近い使い心地。フォルダのアップロードもOK
・GitHub Pages
公開リポジトリなら無料
リポジトリがある人は一番かんたん。更新はpushするだけ
・Vercel（Hobby）
個人利用なら無料
手順はNetlifyに近い。非商用向けだから、文化祭の展示ならOK
・Firebase Hosting
無料枠あり
Googleアカウントで使える。コマンド操作が少し必要

## 文化祭後に公開を停止する

文化祭が終わったら、サイトを非公開にできます。公開を止めると、配布した QR コードや URL から作品を開けなくなります。

1. Netlify で該当のサイトを開き、**Site configuration**（サイト設定）の **General** を開きます。
2. 一番下の **Danger zone** にある **Delete this site** で、サイトを削除します。メニューの名前は画面の表示に従ってください。
3. 後で再公開する可能性があるときは、削除せずに、中身が空の `index.html` だけをアップロードして上書きする方法もあります。

手元のソースファイルは、サイトを削除しても残ります。

## 公開前に確認すること

- 公開したサイトは、インターネットから誰でも閲覧できます。
- QRコードのURLには、**入力された名前とふりがなが含まれます**（文字は変換されており、そのままは読めませんが、URLを解読すれば取り出せます）。展示の来場者には、その旨を伝えておくと安心です。
- 画像ファイルをサーバーへアップロードする仕組みではありません。スマホ側で、URLの情報から作品を描き直して画像を作ります。
- ソースファイルに、公開したくない個人情報や秘密情報が含まれていないことを確認してください。
